# Лабораторна робота №3

## Тема

Візуалізація даних

## Мета роботи

Навчитися виконувати очищення даних та будувати інформативні графіки для аналізу багатовимірного датасету.

## Обраний датасет

Для виконання лабораторної роботи використано датасет **Adult / Census Income** з UCI Machine Learning Repository.

Датасет відповідає вимогам лабораторної роботи:

- Dataset Characteristics: Multivariate
- Attribute Characteristics: Categorical, Integer
- Number of Attributes: 14
- Є щонайменше 2 числові атрибути
- Has Missing Values: Yes

## Завдання

Необхідно:

1. Обрати датасет, що відповідає вимогам.
2. Виконати Data Cleaning.
3. Побудувати графік залежності одного числового атрибута від іншого.
4. Побудувати гістограму по одному з атрибутів з 5 діапазонами.
5. Побудувати графіки для аналізу багатовимірних даних.
6. Побудувати додаткові графіки, що показують корисну інформацію про датасет.
