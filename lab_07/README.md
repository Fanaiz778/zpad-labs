## Керування програмою

| Клавіша | Дія |
|---|---|
| `1` | Звичайне зображення |
| `2` | Інверсія кольорів |
| `3` | Gaussian Blur |
| `4` | Canny filter |
| `5` | Sobel filter |
| `6` | Grayscale |
| `7` | Binary threshold |
| `8` | Glitch effect |
| `F` | Увімкнути / вимкнути детекцію облич |
| `L` | Увімкнути / вимкнути штучну затримку детектора |
| `W`, `A`, `S`, `D` | Переміщення хрестика |
| `Q`, `E` | Обертання зображення |
| `+`, `-` | Зум |
| `R` | Скидання трансформацій |
| `ESC` | Вихід |

Миша:

- ЛКМ натиснути та потягнути — намалювати прямокутник.
- Колесо миші вгору/вниз — зум.

Слайдер:

- `Brightness` змінює яскравість кадру.

## Архітектура

- `CameraProvider` — читає кадри з камери через `cv::VideoCapture`.
- `KeyProcessor` — обробляє натиснуті клавіші та перемикає режими.
- `FrameProcessor` — виконує базову обробку кадрів залежно від активного режиму.
- `FaceDetector` — виконує асинхронну детекцію облич у фоні за допомогою `std::thread`, `std::mutex`, `std::condition_variable` та `std::atomic<bool>`.
- `Display` — відповідає за показ кадру через `cv::imshow`.
- `main.cpp` — створює об'єкти класів і містить основний цикл програми.

## Опис багатопотоковості

Основний потік:

1. Зчитує кадр з камери.
2. Якщо режим детекції облич увімкнено, передає копію кадру в `FaceDetector`.
3. Забирає останні відомі координати облич.
4. Малює рамки на поточному кадрі.
5. Відображає результат через `cv::imshow`.

Фоновий потік:

1. Чекає на новий кадр.
2. Виконує `cv::dnn::blobFromImage`.
3. Запускає `net.forward()`.
4. Фільтрує результати з `confidence > 0.5`.
5. Оновлює координати знайдених облич під захистом `std::mutex`.
6. Повторює цикл, поки програма не завершується.

## Очікуваний результат

Після запуску програма відкриває відео з камери.  
Після натискання клавіші `F` увімкнеться режим детекції облич. Навколо знайдених облич будуть намальовані прямокутники.

Клавіша `L` додає штучну затримку `500 ms` у фоновий детектор. Це дозволяє показати перевагу багатопотокової обробки: відео залишається плавним, хоча рамки можуть оновлюватися із затримкою.
