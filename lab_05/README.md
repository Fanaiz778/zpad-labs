# Лабораторна робота №5

## Тема

Наука про дані: обмін результатами та початковий аналіз

## Мета роботи

Створити веб-додаток із використанням Streamlit для аналізу часових рядів VCI, TCI та VHI на основі даних із лабораторної роботи №2.

## Завдання

Необхідно створити Streamlit-додаток, який містить:

- dropdown список для вибору часового ряду: VCI, TCI або VHI;
- dropdown список для вибору області;
- slider для вибору інтервалу тижнів;
- slider для вибору інтервалу років;
- button для скидання всіх фільтрів;
- три вкладки:
  - таблиця з відфільтрованими даними;
  - графік відфільтрованих даних;
  - графік порівняння даних по областях;
- checkbox для сортування за зростанням;
- checkbox для сортування за спаданням;
- розміщення інтерактивних елементів в одній колонці, а графіків і таблиці — в іншій.

## Структура директорії

```text
lab_05/
├── README.md
├── requirements.txt
└── app.py
```

## Вимоги до системи

- Python 3.10 або новіший
- pip
- браузер для відкриття Streamlit-додатку

## Встановлення залежностей

```bash
pip install -r requirements.txt
```

## Запуск додатку

```bash
streamlit run app.py
```

Після запуску Streamlit відкриє веб-додаток у браузері.

## Дані

Дані VCI, TCI та VHI автоматично завантажуються з відкритого NOAA-джерела, як і в лабораторній роботі №2.

Згенеровані файли даних зберігаються локально в директорії `data/` і не додаються до репозиторію.

## Опис функціоналу

У додатку можна:

1. Обрати часовий ряд VCI, TCI або VHI.
2. Обрати область України.
3. Вибрати діапазон тижнів.
4. Вибрати діапазон років.
5. Відсортувати дані за зростанням або спаданням.
6. Скинути фільтри до початкового стану.
7. Переглянути таблицю відфільтрованих даних.
8. Побудувати графік для обраної області.
9. Порівняти середні значення обраного показника між областями.

## Примітка щодо сортування

Якщо користувач одночасно увімкне сортування за зростанням і спаданням, додаток покаже попередження та залишить дані без сортування.
