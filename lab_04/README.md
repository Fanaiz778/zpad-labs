# Лабораторна робота №4

## Тема

Візуалізація даних 2

## Мета роботи

Створити інтерактивну програму для побудови графіка гармоніки з шумом, керування параметрами сигналу та шуму, а також фільтрації зашумленого сигналу.

## Завдання

Необхідно реалізувати програму, яка дозволяє:

- будувати графік гармоніки;
- накладати шум на гармоніку;
- змінювати амплітуду, частоту та фазу гармоніки;
- змінювати параметри шуму;
- вмикати або вимикати шум;
- скидати параметри до початкових значень;
- фільтрувати зашумлений сигнал;
- порівнювати чистий, зашумлений та відфільтрований сигнал.
