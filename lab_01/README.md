# Лабораторна робота №1

## Тема

Наука про дані: інструменти

## Мета роботи

Ознайомитися з базовими інструментами для роботи з даними, зокрема з бібліотеками та підходами для аналізу, очищення та візуалізації даних.

## Завдання

Необхідно пройти короткі курси на платформі Kaggle:

1. Pandas
2. Data Cleaning
3. Data Visualization

Після проходження курсів потрібно отримати сертифікати та надіслати їх викладачу.

## Посилання на курси

- [Pandas](https://www.kaggle.com/learn/pandas)
- [Data Cleaning](https://www.kaggle.com/learn/data-cleaning)
- [Data Visualization](https://www.kaggle.com/learn/data-visualization)

## Хід виконання роботи

1. Зареєструватися або увійти в акаунт Kaggle.
2. Пройти курс **Pandas**.
3. Пройти курс **Data Cleaning**.
4. Пройти курс **Data Visualization**.
5. Отримати сертифікати після завершення кожного курсу.
6. Надіслати сертифікати викладачу.

## Результат

У результаті виконання лабораторної роботи були опрацьовані базові інструменти для роботи з даними:

- обробка табличних даних за допомогою pandas;
- очищення даних;
- базова візуалізація даних.
